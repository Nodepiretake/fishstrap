# Fishstrap

### A better Roblox launcher for Windows

Fishstrap is an open-source Roblox launcher for Windows that brings FPS unlocking, custom bootstrapper options, and improved multi-instance support. A clean alternative to Bloxstrap with additional features.

<br>

---

## Features

| | |
|:---|:---|
| **FPS Unlocker** | Remove the 60fps cap for smoother gameplay on capable hardware |
| **Multi-Instance** | Launch multiple Roblox accounts simultaneously from the same PC |
| **Custom Integrations** | Discord Rich Presence, custom launch flags, and more |
| **Open Source** | Transparent codebase — no hidden telemetry or data collection |
